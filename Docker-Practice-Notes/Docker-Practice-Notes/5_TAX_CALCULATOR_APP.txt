    ----means
	

		Without image:

		```yaml
		services:
		  service-a:
			build: ./service-a
		```

		→ Builds the image from `./service-a`, but Compose assigns the image name.

		With image:

		```yaml
		services:
		  service-a:
			build: ./service-a
			image: mishalpandey/tax-calculator-service-a:latest
		```

		→ Builds the image and explicitly names/tags it as `mishalpandey/tax-calculator-service-a:latest`. and if from dockerhub account mishalpandey/tax-calculator-service-a:latest
		 already exist so in place of building the image from givne build path (build: ./service-a) it will just pull the image


        With image only:

		```yaml
		services:
		  service-a:
			image: mishalpandey/tax-calculator-service-a:latest
		```
		
		→ pull the image from here `mishalpandey/tax-calculator-service-a:latest` and will use it for running the image
		
		
		In short:

		```text
		build  → Where to build the image from
		image  → What to name/tag the image
		```

		The `image:` name is especially useful when pushing the image to Docker Hub.
