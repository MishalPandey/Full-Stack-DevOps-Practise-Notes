TAX CALCULATOR FULL STACK APP-->>



Without Docker Compose File-->>






1.1--> Create all three service service-a, service-b, frontendApp

1.2--> Add DockerFile in backend application service-a, service-b


service-a   ->  DockerFile
				FROM eclipse-temurin:21-jdk
				WORKDIR /app
				COPY build/libs/*.jar app.jar
				EXPOSE 3000
				CMD ["java", "-jar", "app.jar", "--server.port=3000"]
			
service-b   ->  DockerFile
				FROM eclipse-temurin:21-jdk
				WORKDIR /app
				COPY build/libs/*.jar app.jar
				EXPOSE 4000
				CMD ["java", "-jar", "app.jar", "--server.port=4000"]
				

1.3--> .\gradlew.bat clean build
        --> to create build/libs/*.jar file inside your service-a, service-b
		
		
1.4--> docker build -t service-b .\service-b\
   --> docker build -t service-a .\service-a\
   
       --> build both image locally 
   
Building Network between service-a, service-b  -->>
   
   
1.5--> docker network create tax-network
       --> create a network named tax-network 
	   
1.6--> docker run -d --name service-b -p 3200:4000 --network tax-network service-b
       --> running image service-b or up the contaniner of image service-b, named as service-b and port mapping at 3200, because contaniner ke andar 4000 pe service-b pick hoga.
	   
1.7--> docker run -d --name service-a -p 3100:3000 --network tax-network -e TAX_SERVICE_URL=http://service-b:4000 service-a
       --> running image service-a or up the contaniner of image service-a, named as service-a and port mapping at 3100, because contaniner ke andar 3000 pe service-a pick hoga.
	   --> why?? TAX_SERVICE_URL=http://service-b:4000 and not TAX_SERVICE_URL=http://service-b:3200 aur service-b is running at our computer at 3200 then why setting up environment variable this??
	   
	   TAX_SERVICE_URL=http://service-b:4000, means http://CONTAINER_NAME:Running_port_inside_container, so thats why 4000 not 3200,
        3200 port pe hamare computer me hum access kar sakte service-b ke controllers ko but inside the contaniner its running at 4000
          aur jo network humne banaya hai uske andar dono created service-a and service-b run honge jo ki unke hi port pe run honge

With Docker Compose File-->>

  -->>For service-a and service-b Only
  
  
  
  

1.1--> create docker-compose.yaml file 
       
	    --> docker-compose.yaml
	   
		    services:
			  service-a:
				build: ./service-a        ---->>> giving the path where dockerfile exists for building the image
				ports:
				  - "3100:3000"                                                             ---->>> port mapping
				depends_on:                        ---->> Means it will build the service-b FIRST then service-a
				  - service-b
				environment:                                          
				  - TAX_SERVICE_URL=http://service-b:4000

			  service-b:
				build: ./service-b
				ports:
				  - "3200:4000"
				  
		--> docker compose up -d
